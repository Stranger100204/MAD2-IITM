# Trekking Management Application (TMA)

A full-stack web application for managing trekking activities, built as part of the **Modern Application Development II (MAD 2)** course at **IIT Madras**.

The application enables **Admins**, **Trek Staff**, and **Trekkers** to efficiently manage trekking operations, including trek creation, staff assignment, participant registrations, bookings, and activity tracking through role-based access control.

## Tech Stack

- **Backend:** Flask, Flask-RESTful
- **Frontend:** Vue.js, Bootstrap
- **Database:** SQLite
- **Caching:** Redis
- **Background Jobs:** Celery + Redis
- **Authentication:** JWT / Token-based Authentication

## Key Features

- Role-based authentication (Admin, Staff, Trekker)
- Trek and booking management
- Staff assignment and participant tracking
- Search and filtering of treks
- Redis caching for improved performance
- Asynchronous background jobs and scheduled reports
- Responsive user interface

> Developed for the IIT Madras BS Degree – Modern Application Development II course.
